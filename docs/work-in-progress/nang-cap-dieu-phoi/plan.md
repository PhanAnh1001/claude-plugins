# Plan: nâng cấp điều phối và switch hybrid-hands + Paseo

## Tóm tắt

- **Mục đích:** thực hiện [spec](spec.md) theo 3 đợt, **12 task**, ưu tiên **THẤP**, sau [đồng bộ tài khoản](../dong-bo-tai-khoan/plan.md).
- **Trạng thái:** **chờ duyệt**, ngày **10/11/2026**; người dùng đã chốt hướng, phiên sau duyệt chi tiết trước triển khai. Tất cả checkbox đang mở; lượt này chỉ tạo tài liệu.
- **Kết luận:** đợt 1 sửa phân loại và admission trước, đợt 2 dùng registry chung, đợt 3 nối Paseo và quyết định browser guard dựa bằng chứng listener.
- **Người đọc phải làm:** chốt câu hỏi trong spec, xác nhận phụ thuộc và cắt brief có phạm vi ghi. Brain review và phát hành; hand không commit/push/cài runtime.
- **Nguồn:** không có nguồn internet, nguồn nội bộ: [nghiên cứu mục 4](../../research/2026-11-10-switch-model-provider-account/report.md), [AGENTS.md](../../../AGENTS.md), mẫu [hh-store spec](../hh-store/spec.md) và [plan](../hh-store/plan.md). Thiết kế/task tương lai là **suy luận/đề xuất**.

## 1. Quy ước thực hiện và kiểm chứng

Các đường dẫn rút gọn `lib/`, `config/`, `hooks/`, `scripts/` ở dưới thuộc `hybrid-hands/plugins/hybrid-hands/`; `tests/` thuộc `hybrid-hands/tests/`. File mới ghi rõ “dự kiến”. Lệnh Python chạy từ gốc repo, fixture giả và state tạm, không gọi subscription/model thật. Tên selector mới là dự kiến, phải tạo test tương ứng rồi xác nhận có test được chạy; không claim xanh nếu selector chọn 0 ca.

Mức test tối thiểu, **tổng tối đa 3 ca quan trọng mỗi đợt**, gom assert/tham số vào ca sẵn có; không full suite. Không viết test cho text tài liệu. Riêng browser guard chống tấn công ngoài bỏ giới hạn tối thiểu, kiểm kỹ và thực nghiệm staging. Không đọc `.env`, token, credential, transcript/log thật; không gọi API trả phí. Brain kiểm runtime bằng metadata/usage tổng hợp theo luật repo.

## 2. Đợt 1 — phân loại, breaker, quota và doctor

Phụ thuộc: sync tài khoản xong, spec được duyệt; T1 trước T2 để report không kích breaker giả. T2–T4 cùng admission/config phải tuần tự nếu chạm cùng file.

- [ ] **T1 — tái hiện và sửa lỗi auth giả.** File: `lib/hand_ext/backends/claude.py`, `lib/hand_ext/runner.py` nếu đường phân loại cần, `tests/test_hand_ext_claude.py`, fixture trong `tests/fixtures/hand_ext/`. Xong khi fixture report có “Not logged in” + exit 0 đỏ đúng lỗi trước sửa, xanh `completed` sau sửa; auth thật vẫn được nhận từ tín hiệu CLI đáng tin, không đọc transcript run thật. Kiểm hẹp: `python3 -I -m unittest discover -s hybrid-hands/tests -p 'test_hand_ext_claude.py' -k report_not_logged_in` (selector dự kiến; ca 1).
- [ ] **T2 — circuit breaker có hạn.** File: `lib/hand_ext/quota_state.py`, `run_cmd.py`, `constants.py`, `config.py`, `tests/test_hand_ext_core.py`. Xong khi lỗi hạ tầng xác thực đủ ngưỡng mở cooldown, pick/auto nêu lý do, hết hạn có probe atomic, lỗi code không retry; giữ exit 7/8 và chống writer trùng. Kiểm hẹp: `python3 -I -m unittest discover -s hybrid-hands/tests -p 'test_hand_ext_core.py' -k circuit_breaker` (ca 2 tham số: mở/phục hồi và lỗi code).
- [ ] **T3 — quota mọi account và doctor kín dữ liệu.** File: `lib/hand_ext/day_budget.py`, `config.py`, `constants.py`, `run_cmd.py`, `native.py`, `cli.py`, `backends/claude.py`; helper mới dự kiến `account_metadata.py`; `tests/test_hand_ext_defaults.py`. Xong khi 3 ngưỡng áp đúng vN/codex, thiếu nguồn đang bật bị chặn ở cả native/terminal, doctor chỉ hiện plan/trùng/unknown, không lấy token hoặc in định danh. Kiểm hẹp: `python3 -I -m unittest discover -s hybrid-hands/tests -p 'test_hand_ext_defaults.py' -k account_guard_doctor` (ca 3 tham số: hợp lệ, đạt ngưỡng/unknown, metadata trùng/không đủ). Brain xác minh metadata thực không hiển thị định danh; nếu helper không khả thi giữ unknown, báo duyệt.
- [ ] **T4 — phát hành đợt 1.** File: `hybrid-hands/README.md`, plugin `.claude-plugin/plugin.json`, `CHANGELOG.md`. Xong khi brain review, 3 ca trên xanh, tăng version thích hợp theo main lúc gộp và ghi changelog; cập nhật plugin bằng CLI chính thức cho repo hiện tại và mọi repo đang dùng, không bật repo mới; kiểm version + đường dẫn thực nạp, báo reload nếu không hot load. Kiểm hẹp manifest: `python3 -I -m json.tool hybrid-hands/plugins/hybrid-hands/.claude-plugin/plugin.json`; brain chạy validate/cài theo CLI chính thức sau kiểm help, ghi nguyên lệnh/kết quả và danh sách repo trong bàn giao. Brain điều phối commit/push/merge theo AGENTS.md.

## 4. Đợt 3 — provider Paseo và browser guard có điều kiện

Phụ thuộc: đợt 2 phát hành. T9 trước T10; không thêm listener mới. Nhánh bảo mật T11 chỉ mở sau bằng chứng từ T10.

- [ ] **T9 — sinh hh-hand-* cùng config.** File: `lib/hand_ext/paseo_provider.py`, `paseo_names.py`, `backend_registry.py` dự kiến từ T5, `tests/test_hand_paseo_provider.py`. Xong khi bỏ danh sách backend cứng, dry-run diff đúng, apply idempotent bằng công cụ chính thức, giữ provider không thuộc plugin; rollback phần sở hữu. Kiểm hẹp: `python3 -I -m unittest discover -s hybrid-hands/tests -p 'test_hand_paseo_provider.py' -k registry_provider` (ca 1 tham số: sinh tương đương và apply lặp/giữ ownership).
- [ ] **T10 — xác minh bề mặt nghe cổng.** File: cập nhật spec mục 5 và plan task này bằng bằng chứng; đọc `hybrid-hands/paseo-hh-tree/index.server.ts`, `server/*`, manifest và đường RPC host. Xong khi ghi rõ plugin có/không sở hữu listener, Host/Origin được xử lý ở đâu; chưa rõ thì chặn T11, không đoán. Kiểm tĩnh hẹp: `rg -n 'listen\(|createServer|WebSocket|server.handle' hybrid-hands/paseo-hh-tree`; brain kiểm listener thực bằng `lsof -nP -iTCP -sTCP:LISTEN` rồi chỉ báo cổng/process liên quan, không lưu dữ liệu tài khoản. Không thêm test code.
- [ ] **T11 — browser guard hoặc N/A có bằng chứng.** File nếu có listener: module listener xác định ở T10, helper/test guard mới trong `hybrid-hands/paseo-hh-tree/server/` nếu thuộc plugin; `package.json` chỉ nếu cần lệnh kiểm. Xong khi Host/Origin/DNS rebinding và transport thực được chặn đúng, không phá RPC hợp lệ. Nếu không có listener plugin sở hữu: ghi N/A và việc cần chuyển chủ host, không tự sửa Paseo ngoài repo. Kiểm hẹp dự kiến từ `hybrid-hands/paseo-hh-tree`: `node --experimental-strip-types --test server/browser-guard.test.ts` (phải điều chỉnh runner theo môi trường hỗ trợ); `npm run typecheck`. Đây là **mức kỹ**: ca hợp lệ, Origin thiếu/null/khác, Host giả, DNS rebinding, port/scheme, proxy header, WebSocket theo transport; brain chọn công cụ SAST sẵn có, chạy dependency scan `npm audit --omit=dev`, DAST staging bằng request thật và ghi lệnh/kết quả, không cài tool/gọi API trả phí. Nếu thiếu môi trường staging/tool thì báo chưa kiểm, không claim đạt. Nhánh N/A không có test này; tối đa ca 2–3 thông thường dành cho hồi quy RPC/provider khi cần.
- [ ] **T12 — phát hành đợt 3.** File: README, plugin manifest, CHANGELOG; `hybrid-hands/paseo-hh-tree/{paseo-plugin.json,package.json}` nếu panel thay đổi. Xong khi brain review, test hẹp T9/T11 và bằng chứng T10 đạt; nhánh guard có đủ kiểm kỹ. Tăng version thích hợp/changelog, validate manifest bằng `python3 -I -m json.tool` trên từng file đổi, cập nhật tất cả repo đang dùng qua công cụ chính thức; kiểm version/đường dẫn runtime và reload cần thiết. Brain ghi lệnh thật và điều phối commit/push/merge theo AGENTS.md; không tự bật plugin ở repo khác.
