# Ghi chú nguồn: Paperclip

## Tóm tắt

Paperclip là control plane self-hosted, MIT, để điều hành "công ty" gồm các AI agent. Mọi fact dưới đây lấy từ README GitHub [https://github.com/paperclipai/paperclip](https://github.com/paperclipai/paperclip), truy cập 11/11/2026; chưa đọc docs chi tiết, chưa chạy thử.

## Fact

- Định vị: "The open-source app everyone uses to manage agents at work"; "If OpenClaw is an employee, Paperclip is the company" ([nguồn](https://github.com/paperclipai/paperclip), 11/2026).
- Org chart: agent có role, title, reporting line, permission, budget ([nguồn](https://github.com/paperclipai/paperclip), 11/2026).
- Ticket + atomic checkout: "A single assignee and execution locks prevent competing runs from claiming the same task"; ticket có comment, document, blocker dependency ([nguồn](https://github.com/paperclipai/paperclip), 11/2026).
- Budget: theo company/agent/project, cảnh báo ngưỡng, tự pause khi chạm giới hạn ([nguồn](https://github.com/paperclipai/paperclip), 11/2026).
- Heartbeat: agent thức dậy khi có việc được giao, follow-up hoặc lịch ([nguồn](https://github.com/paperclipai/paperclip), 11/2026).
- Governance: các bước review/approval chặn việc và việc "hire" agent; operator pause/reassign/stop ([nguồn](https://github.com/paperclipai/paperclip), 11/2026).
- Dashboard: theo dõi việc, chi phí, agent, cả trên mobile ([nguồn](https://github.com/paperclipai/paperclip), 11/2026).
- Audit: mutating action, cost event, approval ghi thành activity bền; config có revision, rollback được ([nguồn](https://github.com/paperclipai/paperclip), 11/2026).
- BYO agent: adapter cho Claude Code, Codex, OpenClaw, Cursor, Gemini CLI, process/HTTP tuỳ biến, plugin adapter ngoài ([nguồn](https://github.com/paperclipai/paperclip), 11/2026).
- Goal ancestry: task/project gắn tới mục tiêu tổ chức để agent biết "vì sao" ([nguồn](https://github.com/paperclipai/paperclip), 11/2026).
- Độ phổ biến: khoảng 113k sao, 18.8k fork (số do GitHub hiển thị qua công cụ fetch, chưa kiểm chéo) ([nguồn](https://github.com/paperclipai/paperclip), 11/2026).
- Chưa xác minh: trang https://paperclip.ing không được đọc trong lần này.
